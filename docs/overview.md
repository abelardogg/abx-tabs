Este proyecto es un reproductor local sin fines de grupo para tablaturas de guitarra y mas instrumentos solo con fines de apoyar al aprendizaje, no tiene fines de lucro y no almacena tablaturas solo las lee del explorador de archivos del dispositivo donde se ejecuta. 

- esta pensado para verse en PC asi que no es responsive
- Puede leer los archivos con extensiones gp de guitar pro
- La app tiene play, pause, control de tiempo, fijar un segmento para que se reproduzca en loop.
- de manera default hay un instrumento en pantalla como en guitar pro y se pueden ir cambiando para ver la tab de otro pero en estepodemos hacer split screende hasta 3 instrumentos a la vez de forma vertical aprovechando el ancho de las pantallas de escritorio. 
- incluye metronomo
- incluye visualizacion de la afinacion del instrumento
- transposicion de tono, osea poder bajar todas las cuerdas en semitonos hacia arriba o abajo pero sin cambiar los trastes que se tocan 
- una opcion de ajuste de notas para cmabiar semitonos y encontrar la nota como en la afinacion original
- TAambien control de teclado, space para pause play, moverse con las flechas en ambos ejes, y doble click a la flecha para saltar entre secciones
